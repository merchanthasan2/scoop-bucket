# NetSpeed Boss Scoop Bucket

Official [Scoop](https://scoop.sh) bucket for **NetSpeed Boss**.

## Install

```powershell
scoop bucket add netspeedboss https://github.com/merchanthasan2/scoop-bucket
scoop install netspeedboss
```

## Available Packages

| Package | Description | Homepage |
| --- | --- | --- |
| `netspeedboss` | Live network upload and download speed on your Windows taskbar | [NetSpeed Boss](https://merchanthasan2.github.io/NetSpeedBoss/) |
